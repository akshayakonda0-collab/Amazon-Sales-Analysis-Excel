📊 Amazon Sales Analysis Dashboard — Excel


📌 Project Overview
This project analyzes Amazon sales data using Microsoft Excel and presents the results through an interactive sales dashboard.

The dashboard provides insights into sales performance across categories, cities, brands, months, payment methods, and order statuses.

The project demonstrates practical Excel skills used in data analysis and business reporting.

🎯 Objectives

The main objectives of this project were to:
Analyze overall sales performance
Identify top-performing categories and brands
Compare sales across different cities
Analyze monthly sales trends
Understand order and payment patterns
Create an interactive dashboard for business analysis
Present key findings in an easy-to-understand visual format

📊 Dashboard Features

The dashboard contains four main visualizations:
1. Sales by Category
Shows total sales generated by each product category.
Key finding: Electronics is the highest-performing category.

2. Monthly Sales Trend
Shows how sales changed from January to June.
Key finding: June recorded the highest monthly sales.

3. Sales by City

Compares sales performance across different cities.
Key finding: Bengaluru generated the highest total sales.

4. Sales by Brand

Shows total sales generated by different brands.
Key finding: Apple was the top-performing brand.
🎛️ Interactive Filters

The dashboard includes four slicers:
City
Category
Payment Method
Order Status

These slicers allow users to interactively filter the dashboard and analyze specific segments of the sales data.
For example, users can select:
Bengaluru + Electronics + Delivered
and the dashboard automatically updates the charts and KPI values.

🔍 Key Insights
Electronics generated the highest sales among all categories.
Bengaluru was the top-performing city by total sales.
June recorded the highest monthly sales.
Apple was the highest-selling brand.
Interactive filtering allows sales performance to be analyzed across different customer and order segments.
